# 프로그램 담당 매니저

오너와 플랫폼 관리자는 프로그램 상세 화면의 **담당 매니저**에서 같은 고객사의 매니저 계정을 복수 선택하거나 배정을 해제할 수 있다.

매니저의 사전등록 목록·등록·중지와 참여 프로그램 변경은 담당 프로그램으로 제한한다. 프로그램 이동은 출발·도착 프로그램 모두 담당해야 한다. 담당이 없으면 이 두 운영 화면의 프로그램 목록은 비어 있다. 기존 대시보드 조회와 코치 배정은 별도이며 이번 변경에 포함하지 않는다.

`program_managers`는 고객사 소속 외래 키와 프로그램/역할 검증 트리거를 사용한다. 인증 클라이언트의 직접 쓰기는 허용하지 않는다. 서버 액션은 인증된 고객사와 사용자 ID를 서비스 전용 RPC에 전달하고, RPC가 현재 역할 및 담당 여부를 검증한다. 배정 변경과 운영 작업은 프로그램 행 잠금으로 조정한다.

DB 배정은 적용되었다. 배정 편집 화면과 사전등록 서버 액션의 새 RPC 호출은 웹 코드 배포가 필요하다.

## 검증

- `pnpm test:program-managers`: 인증 주체 고정, 오너/관리자 권한, 미배정 범위, 배정 해제, 잘못된 입력, DB 오류 처리.
- 운영 DB 트랜잭션에서 담당 프로그램 등록·중지 성공, 다른 지점 조회·등록·이동 차단, 매니저의 배정 변경 차단, 배정 해제 후 권한 회수를 검증하고 전부 롤백했다.
- 기존 요청 복구·청구·회원 검색·월간 통계 회귀 검사와 TypeScript 검사, lint, 프로덕션 빌드를 통과했다.
